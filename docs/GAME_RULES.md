資料を要約して記録している。公式説明は完全な仕様書ではなく、宣伝画像は現行実機の証拠と区別する。類似ゲームの説明やレビューから詳細仕様を確定しない。

確認状態は次の意味で使用する。

- **公式説明**: メーカーの説明に記載がある。境界条件や計算式まで確定したという意味ではない。
- **画像観察**: 公式画像に見える。実機版での再確認が必要。
- **動画観察**: 提供録画で条件と結果を確認した。撮影版が不明なら現行Android版の確定仕様にはしない。
- **ユーザー確認**: ユーザーがプレイ経験から明言した仕様。映像で再観察したという意味ではなく、版・時刻が未記録ならその制約を残す。
- **実機確認**: 比較対象のバージョンで観察記録と期待結果がある。
- **推定**: 観察から候補を絞ったが、別の説明も成立する。
- **未確認**: 根拠が足りず、実装上の仮定も公式仕様に昇格させない。

## ユーザーの補足による仕様整理

2026-10-10のS5を反映。動画観察の制約はそのまま残し、現在の判断をここに記す。

| 項目 | 現在の仕様・判断 | 根拠と残る条件 |
| --- | --- | --- |
| 同時合体 | 起点を含む同値m個で `n × 2^(m-1)`、m=2～4。16なら32・64・128 | 2・4個はS4、3個はユーザー確認S5。直接隣接か連結集合かは未確定 |
| 隣接方向 | 斜めは合体しない。上方向なしは推定 | S5。起点を投入ブロックとその合体結果に限るなら、上に既存ブロックがない説明と整合。既存ブロック起点の連鎖は別途確認 |
| 上端 | 最上段への設置は合体可能な場合に救済される。合体前に終了せず、合体後に判定 | ユーザー確認S5。異値を置いて終了したS4と整合。盤面外への追加投入の許可とは同一視しない |
| 生成上限 | 過去に合成した最大値Mに対して `min(M/2,128)` | ユーザー確認S5。現在盤面の最大値と履歴最大値を区別。初期Mの扱い、候補下限、更新時期は未確定 |
| 生成確率 | 候補間で均等という仮説 | ユーザー推定S5。確定仕様として扱わない |
| 合成上限 | 約400万まで到達可能。上限なしは仮説 | ユーザー確認の到達報告と推定を区別。生成上限128は合成上限ではない |

M=16なら生成上限8、M=128なら64、M≥256なら128という解釈。候補下限を2と仮定した場合、M=16の候補は `{2,4,8}`、M≥256では `{2,4,8,16,32,64,128}`。下限2と初期候補は実装前に暫定設定として明記する。

## プロジェクト固有の要件

- コイン、広告、課金、報酬獲得画面は再現しない。ブースター・復活もゲーム本体の比較対象外。得点は再現対象。
- 手動プレイは自然落下をオン・オフ切り替えられる。AIは自然落下なしのターン制。これはユーザー指定の仕様であり、原作観察の結果とは分ける。
- 自然落下オフでも、配置後の重力・合体・連鎖は共通エンジンで完全に解決する。時間条件の比較は自然落下オンで行う。

提供されたプレイ動画は、[動画解析手順](VIDEO_ANALYSIS.md)に沿ってR01～R30の観察根拠に使える。動画に含まれていない場面は未確認のまま残す。複数合体などは操作前後だけでなく、中間フレームを確認して候補を区別する。

## 暫定仕様の扱い

現時点では公式同等のルールセットを確定していない。以前の構成案で挙げた `n+n → 2n`、指数表現、列選択なども、実装方針と実機の確認結果を分ける。

手動版0.1.0は以下の `prototype-v1` を採用した。未確認の一般化を含むため、公式同等とは扱わない。詳細な操作とデータ形式は[実装ガイド](IMPLEMENTATION.md)を参照。

実機確認後は、この台帳に値・根拠・対象バージョンを追記する。複数の観察が食い違った場合は推定または未確認へ戻し、都合のよい記録だけを採用しない。
