資料を要約して記録している。公式説明は完全な仕様書ではなく、宣伝画像は現行実機の証拠と区別する。類似ゲームの説明やレビューから詳細仕様を確定しない。

確認状態は次の意味で使用する。

- **公式説明**: メーカーの説明に記載がある。境界条件や計算式まで確定したという意味ではない。
- **画像観察**: 公式画像に見える。実機版での再確認が必要。
- **実機確認**: 比較対象のバージョンで観察記録と期待結果がある。
- **推定**: 観察から候補を絞ったが、別の説明も成立する。
- **未確認**: 根拠が足りず、実装上の仮定も公式仕様に昇格させない。
