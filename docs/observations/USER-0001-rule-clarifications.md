## 追加で判別する条件

- 生成候補の下限と、最初の合体前の候補・履歴最大値の初期設定。
- 履歴最大値を更新した手で、新しい上限を現在ブロック・予告のどちらから適用するか。
- 同時合体の対象は直接隣接か、連結する集合全体か。既存ブロックが落ちた際の再合体の起点。
- 合体・重力・連鎖をどこまで解決してから終了判定するか。満杯列への盤面外投入の可否。
- 最小ブロック消去の発動条件と、消去後に生成下限も変わるか。

映像から確認した結果は変更せず、この記録を[台帳](../GAME_RULES.md)の現在の判断に追加する。一様分布・上方向なし・合成上限なしを採用する場合は、検証済み仕様ではなく暫定設定として明記する。
