# Runtime notices

The browser distributes unmodified Pyodide 314.0.7 and its CPython 3.14.2
interpreter/standard-library files from the Pyodide npm package.

- Pyodide source: https://github.com/pyodide/pyodide/tree/314.0.7
- Pyodide license: [Mozilla Public License 2.0](PYODIDE-MPL-2.0.txt)
- CPython source: https://github.com/python/cpython/tree/v3.14.2
- CPython license and included notices: [CPYTHON.txt](CPYTHON.txt)

Existing notices inside the runtime files are retained. Additional Python
packages, including scientific and reinforcement-learning packages, are not
included in this game's browser runtime.
